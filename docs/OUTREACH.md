### Notes before you send
- Send the CEO message only if you have a warm path (a mutual contact or a reply from the recruiter). A cold message to a CEO about a posted job usually reads worse than a good message to the hiring team.
- Do not describe the sample as their system or mention anything about their internal platform: it is built from their public website only, and it uses invented symbols.
- Replace `[link]` after you upload the video (the repo already contains it, but a direct link opens faster).
